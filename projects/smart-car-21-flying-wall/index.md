## 智能车算法与功能框架

## 一、整体算法

系统以定时中断为周期，以传感器数据为输入，以左右轮 PWM 为输出，采用分层控制：

```text
传感器采集
  - 五路电磁传感器
  - 陀螺仪
  - 左右编码器
        |
        v
数据处理与决策
  - 电磁数据滤波和归一化
  - 赛道偏差计算
  - 姿态角和角速度计算
  - 圆环、墙、筒子状态判断
        |
        v
控制量计算
  - 方向位置式 PID
  - 陀螺仪角速度阻尼
  - 差速目标速度
  - 左右轮增量式速度 PID
        |
        v
执行
  - 左右电机 PWM 输出
```

每个控制周期执行一次：

1. 采集并滤波五路电磁传感器数据。
2. 更新陀螺仪姿态和累计角度。
3. 读取并统计左右编码器速度及行驶距离。
4. 计算赛道偏差，并判断当前赛道元素状态。
5. 根据直行或元素场景生成左右轮目标速度。
6. 分别通过速度 PID 调节左右轮 PWM。

### 整体控制关系

```text
赛道偏差 error1
        |
        v
方向外环 PID
        |
        v
差速系数 k + 陀螺仪角速度阻尼
        |
        v
左右轮目标速度
        |
        v
左右轮增量式速度 PID
        |
        v
左右轮电机 PWM
```

赛道元素是叠加在基础循迹上的状态机；直行场景执行普通循迹，进入圆环、墙或筒子场景后执行对应的专用控制策略。

## 二、功能算法

本系统是一辆以电磁传感器为主要输入的智能循迹车，主要功能包括：

- 实时采集五路电磁传感器数据并计算赛道偏差。
- 通过双轮差速和双轮速度闭环实现循迹行驶。
- 结合陀螺仪角速度抑制转向和姿态变化。
- 根据编码器累计行驶距离判断赛道元素状态。
- 支持右环岛、左环岛、墙和筒子等赛道元素。
- 支持赛道元素顺序和重复轮数配置。
- 支持通过菜单调节 PID 和元素控制参数。
- 支持参数保存和启动恢复。

系统控制周期为 5 ms。每个周期依次完成传感器采集、偏差计算、元素判断、目标速度计算和电机控制。

### 1. 电磁循迹算法

#### 1.1 数据滤波

系统使用五路电磁传感器：

- `L1`：左外侧传感器
- `L2`：左内侧传感器
- `M1`：中间传感器
- `R2`：右内侧传感器
- `R1`：右外侧传感器

每路传感器保存最近 5 个采样值：

1. 找出当前窗口中的最大值和最小值。
2. 去除最大值和最小值。
3. 对剩余 3 个采样求平均。
4. 将结果归一化到 `0~100`。
5. 对归一化结果进行上下限约束。

#### 1.2 循迹偏差计算

外侧和内侧传感器差值定义为：

```text
A = L1 - R1
B = 2 × (L2 - R2)
C = (L1 + R1) + |L2 - R2| + 0.2 × M1
```

当 `M1 < 45` 时，使用加权内外侧传感器计算偏差：

```text
若 C >= 1：
    error1 = 30 × (A + B) / C
否则：
    error1 = 0
```

当 `M1 >= 45` 时，使用左右外侧传感器计算偏差：

```text
若 L1 + R1 >= 1：
    error1 = 30 × (L1 - R1) / (L1 + R1)
否则：
    error1 = 0
```

该算法以归一化差值表示车辆相对赛道中线的位置和方向偏差。

### 2. 姿态与角速度算法

陀螺仪系统完成以下处理：

1. 上电后采集多组陀螺仪数据计算零漂。
2. 对加速度数据进行一阶低通滤波。
3. 使用 Mahony 四元数算法融合陀螺仪和加速度计。
4. 计算俯仰角、横滚角和偏航角速度。
5. 对 Z 轴角速度积分，得到环岛转向所需的累计角度。

俯仰角用于墙、筒子和圆环元素的进入或退出判断；累计角度用于判断环岛是否完成。

### 3. 方向控制算法

方向外环使用位置式 PID：

```text
e = 0 - error1
积分项 = limit(积分项 + Ki × e)
output = Kp × e + Kd × (e - 上一次误差) + 积分项
```

方向 PID 输出限制在 `-350~350`，再结合陀螺仪角速度计算差速系数：

```text
k = -direction_PID_output × 0.01 - gyro_angular × BB
k = limit(k, -0.70, 0.70)
```

其中：

- 方向 PID 修正电磁传感器产生的赛道偏差。
- 陀螺仪角速度用于抑制过快转向。
- `k` 表示左右轮的差速比例。

左转时左轮为内轮：

```text
left_target  = run_speed × (1 - k)
right_target = run_speed × (1 + k × 0.25)
```

右转时右轮为内轮：

```text
k = -k
left_target  = run_speed × (1 + k × 0.25)
right_target = run_speed × (1 - k)
```

目标速度最低限制为零，防止车辆倒转。

### 4. 双轮速度控制算法

左右轮分别采用增量式 PID：

```text
e = target_speed - encoder_speed
Δu = Kp × (e - e_previous)
     + Ki × e
     + Kd × (e - 2e_previous + e_previous2)
pid_output += Δu
```

将速度前馈叠加到 PID 输出：

```text
feedforward = target_speed × 3
PWM = pid_output + feedforward
```

最终的左右轮 PWM 分别用于驱动左右电机，从而实现目标差速和目标速度控制。

需要越过坡道或障碍时，若俯仰角超过阈值，可额外叠加固定前馈增强动力。

### 5. 编码器距离算法

左右编码器分别反馈本控制周期内的轮速。系统使用左右轮平均速度计算正向行驶距离：

```text
step = (left_encoder_speed + right_encoder_speed) / 2

若 step > 0：
    accumulated_distance += step
```

编码器距离用于：

- 判断环岛进入、中间和退出阶段。
- 判断墙和筒子的激活与退出条件。
- 防止筒子退出后因残余状态重复触发。
- 控制赛道元素切换。

### 6. 赛道元素顺序

系统支持以下元素：

- 右环岛
- 左环岛
- 墙
- 筒子

元素执行顺序由槽位 `1~4` 配置，槽位越小越先执行；配置为 `0` 时不启用该元素。完成一个元素后，系统推进到下一个元素。

整套元素完成一轮后可进入下一轮，重复轮数可配置为 `1~10`。

### 7. 圆环算法

圆环采用四状态机：

```text
STRAIGHT -> ENTER -> MIDDLE -> EXIT
```

#### 7.1 直行等待状态

按基础循迹速度行驶，并累加编码器距离。当行驶距离达到设定阈值后进入环岛转弯状态。

#### 7.2 环岛进入状态

根据左右环岛方向，设置固定差速，使车辆快速进入环岛。

切换到中间状态的条件包括：

- 累计偏航角达到约 `60°`。
- 编码器行驶距离达到环岛中间阶段阈值。

#### 7.3 环岛中间状态

车辆继续通过基础循迹控制绕行。系统同时检查：

- 累计偏航角是否达到约 `330°`。
- 编码器距离是否超过环岛中间阈值。

满足条件后进入退出状态。

#### 7.4 环岛退出状态

左右轮以相同目标速度直行，退出环岛后累加编码器距离。当退出距离达到阈值时：

1. 清除环岛状态。
2. 重置累计角度。
3. 切换回直线循迹场景。
4. 推进到下一个赛道元素。

圆环入口检测还会综合中间传感器、俯仰角和圆环锁定计数，降低墙、筒子或坡道对圆环的误触发。

### 8. 墙元素算法

墙元素主要使用中间传感器和俯仰角进行判断：

进入条件：

```text
M1_1 > 90
|pitch| >= 40°
连续满足 3 个周期
```

墙激活后累加编码器距离，退出条件为：

```text
wall_distance > 最小通过距离
M1_1 < 50
|pitch| < 5°
连续满足 3 个周期
```

确认退出后，系统推进到下一个元素。

### 9. 筒子元素算法

筒子进入条件为：

```text
M1_1 > 90
|pitch| >= 40°
连续满足 3 个周期
```

筒子激活后累加编码器距离，退出条件为：

```text
cylinder_distance >= 最小通过距离
M1_1 < 50
|pitch| < 5°
连续满足 3 个周期
```

确认退出后，系统先进入距离等待状态，继续前进到设定距离后再推进到下一个元素，防止重复检测。

### 10. 停车保护算法

车辆正常运行时，如果五路传感器信号全部过低，判定为严重丢线并停止电机：

```text
L1 <= 1 &&
R1 <= 1 &&
R2 <= 1 &&
L2 <= 1 &&
M1 < 1
```

此外，在所有元素完成或达到最终停车条件时停止左右电机。
