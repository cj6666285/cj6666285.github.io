## 项目功能与算法说明

本项目采用 **双 MCU（TI M0）＋ MaixCam Pro 视觉方案**。两颗 MCU 分别负责红外循迹与双轮驱动、主控交互与滚珠横杆控制；MaixCam Pro 负责钢珠视觉检测，并通过 UART 向主控 MCU 发送位置数据。

## 红外循迹与双轮驱动

### 职责与功能

循迹 MCU 以红外传感器识别赛道位置，通过左右电机差速调整行驶方向。编码器提供左右轮速度反馈；系统支持循迹/速度控制模式、速度档位、指定点停车、蓝牙参数调节和状态显示。

### 红外位置与循迹误差

工程读取六路红外传感器的数字状态，并按车辆视角从左到右排列。每路传感器对应一个位置权重：

| 传感器位置 | 左 1 | 左 2 | 左 3 | 右 3 | 右 2 | 右 1 |
|---|---:|---:|---:|---:|---:|---:|
| 权重 | +7 | +4 | +1 | -1 | -4 | -7 |

对检测到赛道的传感器，将其权重相加后除以有效传感器数量，得到平均循迹偏差：

```text
error = Σ(active_sensor_weight) / active_sensor_count
```

偏差为正或负表示赛道相对传感器阵列的方向，绝对值表示偏离程度。若当前没有传感器检测到目标颜色，算法保留上一次有效偏差，避免误差突然归零而令车辆错误转向。

### 转向 PD 与差速分配

循迹控制以目标偏差为零。比例项根据当前误差产生转向量，差分项根据误差相邻两次的变化抑制快速偏移：

```text
turn = Kp × error + Kd × (error - previous_error)
```

这里的微分项使用离散误差差值，不除以采样时间。转向量分别加到左右轮基准速度上：

```text
left_target = base_speed + turn
right_target = base_speed - turn
```

左右轮目标速度分别限制在 `0～20` 范围。左右轮增减方向相反，从而形成差速转向。

### 左右轮速度 PI 闭环

每个车轮有独立的 PI 控制器。控制器将目标速度与编码器反馈速度相减得到速度误差，并对误差和积分量分别限幅：

```text
error = limit(target_speed - measured_speed)
integral = limit(integral + Ki × error)
output = limit(Kp × error + integral)
```

输出作为电机 PWM 请求，最终限制在 `0～5000` 范围。循迹模式中左右轮目标速度受转向量影响；速度模式中两轮使用相同目标速度。

### 起步、停车与调参

- 关闭驱动时将左右电机输出清零，并复位控制器状态，避免下次启动沿用旧积分或误差。
- 工程提供软启动逻辑：从较低速度开始逐步增加基准速度；是否启用取决于主控流程配置。
- 指定点停车模块管理启动、运行和完成状态，可按按键或任务状态停止循迹。
- 蓝牙可调整速度 PI 的 `Kp`、`Ki`，循迹 PD 的 `Kp`、`Kd` 以及基准速度。

## 主控交互与滚珠横杆控制

### 职责与功能

主控 MCU 负责主控流程和滚珠横杆执行控制。它接收 MaixCam Pro 发送的视觉横坐标，计算钢珠相对目标位置的偏差，通过步进电机改变横杆角度。工程还提供任务启停、目标位置和控制参数设置、OLED 状态显示及蓝牙操作。

### 视觉串口数据检查

主控按 `AA 55` 帧头解析串口数据，并检查数据长度、异或校验、有效标志和置信度范围。有效帧中的横坐标还必须落在配置的图像范围 `45～475` 像素内。无效标志、校验失败或越界数据不会作为有效位置交给控制器。主循环通过帧序号识别新数据，避免重复处理同一帧。

### 位置滤波与速度估算

位置滤波使用一阶平滑：

```text
filtered_position += α × (measured_position - filtered_position)
```

当前滤波系数 `α=0.9`，因此输出较快跟随新测量，同时削弱部分检测抖动。钢珠速度由环形历史缓冲区中的位置差计算，采用间隔数帧的测量估算速度：

```text
velocity = (current_position - previous_position) × 1000 / elapsed_time_ms
```

速度估算的时间间隔限制在 `5～200 ms`，降低采样间隔异常造成的速度突变。控制器对位置误差设有 `8 px` 死区，死区内的微小误差归零，以减少横杆因视觉噪声反复动作。

### PD 控制与步进电机指令

位置误差定义为滤波后的钢珠位置减去目标像素位置。控制器将位置误差和钢珠速度合成为目标角度：

```text
target_angle = neutral_angle + Kp × position_error + Kd × ball_velocity
```

默认 `Kp=0.14`、`Kd=0.08`；角度限制在 `-15°～+15°`。控制角度换算为步进电机位置：

```text
target_steps = round(target_angle × 8.8889)
```

得到方向和步数后，主控通过 EMM V5 协议发送位置控制指令。控制器还包含针对特定目标位置的角度补偿，以及目标附近的最小动作判断，用于处理机构偏差和静摩擦。

### 视觉丢失保护

主控按 5 ms 周期累计视觉帧年龄，并限制过长的帧间隔。超过丢失保持时间后，视觉状态标记为无效，滤波和速度历史重新初始化；恢复检测时从新测量重新开始跟踪，避免把过期速度带入闭环。

## 钢珠视觉识别

### 职责与功能

视觉端在 MaixCam Pro 上运行 YOLO26 检测钢珠，提取图像坐标并通过 UART 向主控 MCU 发送结果。它还提供画面显示、标定辅助、镜头校正开关及 RTSP、JPEG、WebRTC 视频输出选项。

### 目标筛选与检测中心

YOLO26 对每帧图像返回候选目标框及置信度。若同一帧出现多个候选框，程序只选择置信度最高者，避免多个框同时更新跟踪器。检测框中心作为测量位置：

```text
center_x = box_x + box_width / 2
center_y = box_y + box_height / 2
```

检测置信度阈值用于控制哪些候选框参与后续处理。

### 自适应 alpha-beta 位置滤波

滤波器分别维护横纵坐标位置和速度。收到新测量后，先依据上次位置、速度和时间间隔预测当前位置：

```text
predicted_position = previous_position + velocity × dt
```

再计算测量与预测之间的偏差。偏差较小时使用较低增益以平滑抖动；偏差较大时提高增益，使滤波器更快跟上钢珠运动。当前参数范围为：`α 约 0.20～0.95`、`β 约 0.01～0.12`；时间间隔限制为 `5～100 ms`。

位置通过 alpha 增益修正预测值，速度通过 beta 增益和时间间隔修正。若连续丢失超过 `250 ms`，滤波器清空位置和速度状态，避免恢复检测时继续使用旧轨迹。

### 轴线标定与位置换算

程序使用图像中的轴线起点 `A` 和终点 `B` 作为标定点。将检测点 `P` 投影到轴线上，计算其相对位置比例：

```text
r = ((P - A) · (B - A)) / |B - A|²
```

再根据轴线两端对应的实际刻度 `start_cm` 和 `end_cm` 换算：

```text
position_cm = start_cm + r × (end_cm - start_cm)
```

投影同时可得到检测点到轴线的垂直距离，用于显示或分析目标是否偏离横杆轴线。当前串口发送的是滤波后的横坐标像素值；换算出的厘米位置用于视觉端显示与标定，不作为当前串口帧中的位置字段。

### 串口帧与无目标处理

视觉端发送帧结构为：

```text
AA 55 04 valid x_high x_low confidence xor
```

其中 `x` 是滤波后的横坐标像素值，`confidence` 为检测置信度乘以 100 后的整数，`xor` 是四字节 payload 的异或校验。检测有效时发送坐标与置信度；未检测到钢珠时发送无效标志和清零数据，明确告知主控当前没有有效测量。

## 系统分工

- **循迹 MCU（TI M0）**：红外循迹、差速转向和左右轮速度闭环。
- **视觉端（MaixCam Pro）**：钢珠视觉检测、像素位置滤波及串口数据发送。
- **主控 MCU（TI M0）**：主控操作、视觉数据接收及滚珠横杆步进电机控制。
